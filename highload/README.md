# Высокопроизводительный кошелек

Оригинальный контракт на FunC: [ton-blockchain/highload-wallet-contract-v3](https://github.com/ton-blockchain/highload-wallet-contract-v3).

В этом пакете реализован высокопроизводительный кошелек, оптимизированный для пакетной отправки, защиты от повторного воспроизведения и управления ограниченным состоянием запросов. Тесты включают проверку, группирование и диспетчеризацию действий, внутренние фильтры, обработку тайм-аутов воспроизведения, ограничения на хранение и очистку запросов, а также сквозные потоки.

Сценарии в разделе "scripts/" предоставляют операционные точки входа для развертывания, проверки состояния и отправки данных о передаче: "deploy.tolk", "info.tolk" и "send-transfer.tolk`. Запустите их с помощью `acton script highload-v3/scripts/<имя>.tolk`.
