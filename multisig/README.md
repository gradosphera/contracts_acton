# Мультикошелек

Исходный код контракта на FunC: [ton-blockchain/multisig-contract-v2](https://github.com/ton-blockchain/multisig-contract-v2).

Этот контракт обеспечивает функциональность «N-из-M мультиподписей»: N подтверждающих сторон из предопределенного набора M подтверждающих должны одобрить Заявку для его выполнения.

Каждая Заявка может содержать произвольное количество действий: исходящие сообщения и обновления параметров. Поскольку содержание сообщений произвольно, Заявка может выполнять произвольные высокоуровневые взаимодействия в сети TON: отправка TON, отправка/выпуск жетонов, выполнение административных действий и т.д.
Тесты проверяют базовое поведение мультикошелька, режимы seqno, вспомогательные функции для управления жизненным циклом заявок, константы и пути расчета комиссии, дополнительные инварианты и сквозные пути выполнения.

Скрипты в папке `scripts/` предоставляют собой точки входа для развертывания, проверки состояния, создания заказов и обновления параметров мультиподписи: `deploy.tolk`, `info.tolk`, `new-order.tolk` и `update-params.tolk`. Запускайте их с помощью команды `acton script multisig-v2/scripts/<name>.tolk`.
